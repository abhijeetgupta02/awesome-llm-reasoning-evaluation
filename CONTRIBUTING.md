# Contributing

Thanks for helping improve **Awesome LLM Reasoning Evaluation**.

## Guidelines

- **One resource per pull request.** It keeps review fast and history clean.
- **Put it in the right section.** If no section fits, propose one in your PR.
- **Format:** `- [Name](link) — One sentence on what it is and why it matters.`
- **Be factual and non-promotional.** Describe what the resource does, not how great it is.
- **Quality bar:** the resource should be real, reachable, and genuinely useful for
  evaluating reasoning, reasoning faithfulness, or reasoning failures. No dead links.
- **Alphabetical-ish within a section** is fine; logical ordering (importance) is also fine.

## How to submit

1. Fork the repo and create a branch.
2. Add your entry following the format above.
3. Open a PR with a short title (e.g., `Add: <resource name>`).
4. In the description, include a one-line justification and the link.

## Not accepted

- Paywalled or login-only resources with no public value.
- Self-promotion with no clear relevance to reasoning evaluation.
- Duplicates of existing entries.
